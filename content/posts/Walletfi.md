#WalletContract #wallet
source: [Walletfi](https://www.walletfi.org/)　[WalletFi (@wallet_fi) / Twitter](https://twitter.com/wallet_fi)

gojoさんのプロジェクト
- [Gojo (@gojoalter) / Twitter](https://twitter.com/gojoalter)

使い方
- ウォレットNFTをミントする
    - 自動でCWがdeployされる
- Root Walletを通して、さまざまなContract Walletを使用する
- ウォレットをTradeする
    - [[Lit Protocol]] も PKP NFT も同様

Root Wallet
- web wallet interface
- ![image](https://scrapbox.io/files/6434dba46764e5001c72387b.png)　![image](https://scrapbox.io/files/6434dbd659ac02001b64a219.png)
- こんな感じで表示される
    - Use this walletで使用するウォレットを選択
    - ![image](https://scrapbox.io/files/6434dc09aa4d1c001b1199a8.png)
        - Walletをうることも可能
            - その場合は、事前にウォレットをロックする
                - いつでもunlock可能
            - ロックされた状態でOpenSea等で取引する
                - [https://testnets.opensea.io/collection/wallet-nft-testnet](https://testnets.opensea.io/collection/wallet-nft-testnet)

ユースケース
- NFTをセットで売却する
- SBTを取引する
- Tx履歴を取引する
