使い方
  - ウォレットNFTをミントする
    - 自動でCWがdeployされる
  - Root Walletを通して、さまざまなContract Walletを使用する
  - ウォレットをTradeする
    - [Lit Protocol] も PKP NFT も同様

Root Wallet
  - web wallet interface
  - ![6434dba46764e5001c72387b.png](./img/6434dba46764e5001c72387b.png)　![6434dbd659ac02001b64a219.png](./img/6434dbd659ac02001b64a219.png)
  - こんな感じで表示される
    - Use this walletで使用するウォレットを選択
    - ![6434dc09aa4d1c001b1199a8.png](./img/6434dc09aa4d1c001b1199a8.png)
      - Walletをうることも可能
        - その場合は、事前にウォレットをロックする
          - いつでもunlock可能
        - ロックされた状態でOpenSea等で取引する
          - https://testnets.opensea.io/collection/wallet-nft-testnet

ユースケース
  - NFTをセットで売却する
  - SBTを取引する
  - Tx履歴を取引する
