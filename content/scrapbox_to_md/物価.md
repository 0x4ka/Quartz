 物価を作る
 	物価は個々の商品の価格の集合体
 	価格は、貨幣とそれぞれの商品の交換比率

      - 生計費指数と呼ぶ
    - 生活費指数の計算は難しいので、できるだけ近似しようとする計算方法が現れた
      - ラスパイレス指数
        - 一九世紀に提唱され、日本のＣＰＩ統計も含め、各国で広く使われている物価指数
    商品Aは昨日の100円から90円に変化（0.9倍）し、商品Bは1.4倍変化した
    AとBの昨日の金額シェアを計算
    	(¥100*11こ) / ¥10,000 = 0.11, ...
    0.9 x 0.11 + 1.4 x 0.89 = 1.34 => つまり、物価は昨日より34%上昇した計算となる
    ラスパイレスは、重みとして昨日の金額シェアを用いているため、消費者が今日行った節約行動を織り込めていない
      - パーシェ指数
        - ラスパイレス指数が、昨日を基準に今日を評価していたのに対し、パーシェ指数は今日を基準に昨日を評価するため、時間方向が正反対になっている
          - 計算上の工夫であり最後に時間方向を正しい方向に戻す
        - 商品Aの価格は昨日の0.9倍である => 時間方向が逆なので昨日の価格は今日の 1/0.9倍である、Bは1/1.4倍
        - これを「今日」の金額シェアを使って平均する
          - 1/0.9 x 0.38 + 1/1.4 x 0.62 = 0.86 => 時間方向を戻す 1/ 0.86 = 1.16
        - 今度は過小評価になっている
          - 今日の価格を基準に昨日を評価するため、昨日の節約行動を織り込めていない
      - フィッシャー指数
        - ラスパイレス指数とパーシェ指数を幾何平均した値
