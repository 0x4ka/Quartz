#MultichainID  #WalletContract
- ウォレット　→　ソーシャルアカウント
- さらに言えば、
    - onchain Domain　→　ウォレット　→　ソーシャルアカウント
- ウォレットの秘密鍵を失ったとしても、onchain domain で保有履歴は集約されている
    - しかし、ユーザーが資産を動かせなくなる
        - ソーシャルリカバリーができた方がいい
            - コントラクトウォレットで実装されることが望ましくなる（冗長性）
                - onchain domain → コントラクトウォレット → MPCウォレット → ソーシャルアカウント
                    - 異なるMPCウォレットに対してコントラクトウォレットの権限を与える
                        - 少なくとも2つ以上のSNSアカウントを紐づけることを推奨する（冗長性）
                            - 一方のアカウントを紛失しても復元加納
                            - web3authのようなサービスの仕様が大きく変わる、サービスの提供が終了することへの対策
